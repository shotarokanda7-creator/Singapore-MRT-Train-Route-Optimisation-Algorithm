# Singapore-MRT-Train-Route-Optimisation-Algorithm


A Python Turtle-based MRT route visualizer that can:

- list all stations on a line
- find the fastest route between two stations
- check whether a route is available at a given time
- show interchange stations
- list all lines running through a station
- display step-by-step line change guidance
- calculate a departure time for a desired arrival time
- estimate distance and travel time
- show up to five possible routes

## Requirements

- Python 3
- No external packages are needed
- Uses only Python’s built-in `turtle` module

## How to run

1. Download the Python file and the MRT data text file.
2. Open a terminal in the folder containing the files.
3. Run:

```bash
python "MRT Route Algorithm"
